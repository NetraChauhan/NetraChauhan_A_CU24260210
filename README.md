# Flutter Lab Sheet 2

**Subject:** Basic Flutter Widgets and User Interface Design  
**Course:** BCA  

This repository contains 25 separate Flutter programs based on Lab Sheet 2.

## How to run

Open Terminal inside the project folder and run:

```bash
flutter pub get
flutter run -d chrome -t lib/program_01.dart
```

To run another program, change the number. Example:

```bash
flutter run -d chrome -t lib/program_14.dart
flutter run -d chrome -t lib/program_25.dart
```

Each file is independent and can be run separately.
